# 🌱 꿈자람 학급 경제교실 (Classroom Economy & Growth Quest)

초등학교 4학년을 위한 실천적 학급 경제 & 게이미피케이션 학급 관리 웹 애플리케이션입니다.

---

## ✨ 주요 기능

### 1. 🚪 게이트웨이 (로그인 프리 모드 선택)
- **선생님 모드 / 학생 모드** 간편 선택
- 학생 모드: 1~25번 출석번호 및 아바타 카드를 통한 원클릭 입장

### 2. 👩‍🏫 선생님 모드 (교사용 통합 대시보드)
- **학급 현황 모니터링:** 25명 학생의 잔액(화폐), 누적 경험치(EXP), 레벨 실시간 확인
- **보상 및 차감 시스템:** 개인별 또는 전체/다수 학생 대상 원클릭 화폐 및 경험치 지급/차감
- **1인 1역 관리:** 학급 역할 배정 및 일일 실천 현황 확인
- **오늘의 미션:** 학급 공통/개별 과제 등록 및 완수 체크
- **학급 상점 관리:** 쿠폰/실물 보상 아이템 등록, 가격 책정, 학생의 사용 신청 승인

### 3. 🎒 학생 모드 (학생용 게이미피케이션 화면)
- **성장 대시보드:** 나의 레벨, 뱃지, 보유 화폐, EXP 진행률 시각화
- **오늘의 할 일:** 1인 1역 실천 및 학급 미션 확인 및 완료 체크
- **학급 상점 & 인벤토리:** 모은 화폐로 쿠폰 구매, 보유 쿠폰 확인 및 선생님께 제시 후 사용 완료

---

## 🛠 기술 스택

- **Frontend:** Vanilla JavaScript (ES Modules), HTML5, Vanilla CSS
- **Design:** CSS Custom Properties (Theme tokens), 반응형 카드 레이아웃, 마이크로 인터랙션
- **Effects:** Canvas Confetti, Web Audio FX
- **Bundler / Dev Server:** Vite
